## Data / cloud
★ SnowPro Core, ★ Databricks Data Engineer Associate, dbt Analytics Engineering, AWS Certified Data Engineer – Associate, Azure DP-203/DP-700, Google Professional Data Engineer, Tableau/Power BI (PL-300), SAS (still used in actuarial/health analytics).

## Suggested order
1. Free: HHS HIPAA training + CMS MLN → 2. AHIP fundamentals → 3. A cloud/data cert (SnowPro or Databricks) → 4. CHC or CHPC after you land a compliance-adjacent role → 5. CHDA/CRC if analytics-heavy.
