# 12-Week Study Plan

~10-12 hrs/week. Mix reading, hands-on, and practice problems.

| Week | Theme | Read | Do |
|---|---|---|---|
| 1 | Insurance fundamentals | `01-Industry-Basics` (all) | Make flashcards for [[02 Glossary]]; read a real Summary of Benefits (search "SBC sample" at healthcare.gov) |
| 2 | Plans & money flow | [[Plan Types and Cost Sharing]], [[How Money Flows]] | Calculate 5 patient-cost examples by hand |
| 3 | Enrollment, eligibility, underwriting | `02-Core-Operations` notes 1-3 | SQL basics: [[SQL Practice Plan]] week 1 |
| 4 | Claims lifecycle | [[Claims Lifecycle]], [[Utilization Management and Prior Auth]] | Write a claim-status state diagram |
| 5 | Networks, pharmacy, risk adjustment, fraud | rest of `02-Core-Operations` | SQL window functions |
| 6 | Regulations | `03-Regulations-Compliance` | Build a HIPAA checklist for a pipeline |
| 7 | Code sets & formats | `04-Data-and-Standards` | Parse a sample 837 with Python; look up 10 ICD-10 / CPT codes |
| 8 | FHIR & interoperability | [[FHIR and Interoperability]] | Query the public HAPI FHIR server |
| 9 | Data engineering | `05-Data-Engineering` | Build mini ETL project (see [[Portfolio Projects]]) |
| 10 | Analytics | `06-Analytics` | Compute PMPM, MLR, readmissions on Synthea data |
| 11 | Automation + project polish | `07-Automation` | Finish project, write README, push to GitHub |
| 12 | Interview prep | `10-Interview-Prep` | Mock interviews; apply |

## Daily rhythm (1.5 hr)
- 30 min read one note
- 45 min practice problem(s)
- 15 min write "explain it to a friend" summary in your own words

## Checkpoints
- End wk 4: explain a claim from submission to payment without notes.
- End wk 8: read a 837 claim and say what each segment means.
- End wk 12: have 1 GitHub project, 5 stories, and can whiteboard a claims pipeline.
